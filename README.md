# Task 3: Responsive Webpage Layout

## 📌 Project Description

This project demonstrates a responsive webpage layout created using HTML and CSS. The webpage is designed to adjust to different screen sizes, including desktops, tablets, and mobile devices.

## 🎯 Objectives

* Create a clean and attractive webpage layout.
* Use HTML to structure the webpage.
* Use CSS to style the layout.
* Implement responsive design using CSS media queries.
* Ensure the webpage works on different screen sizes.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Media Queries
* Flexbox and/or CSS Grid

## 📂 Project Structure

```text
task-3-responsive-webpage-layout/
├── index.html
├── style.css
└── README.md
```

## ✨ Features

* Responsive webpage layout
* Clean and user-friendly design
* Organized HTML structure
* Modern CSS styling
* Mobile-friendly layout

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Resize the browser window to test the responsive layout.

## 📚 Learning Outcomes

* Understanding webpage structure with HTML.
* Applying styles using CSS.
* Creating responsive layouts with Flexbox, Grid, and media queries.
* Improving the user experience across different devices.
